# RetailAnalyticsHub
End-to-end retail analytics project transforming raw business data into KPIs, data-quality insights, interactive dashboards, and executive decisions.

### Task 02 — KPI Dictionary & Data Quality

This task focuses on defining measurable business KPIs and establishing a data-quality framework for a retail dataset.

Key work includes:

* Created definitions for 10 business KPIs
* Documented KPI formulas and data grain
* Added business filters, ownership, and refresh frequency
* Evaluated completeness, uniqueness, validity, consistency, and freshness
* Developed executable data-quality checks using Python and Pandas
* Documented quality thresholds and escalation procedures

### Task 03 — Data Ingestion, Cleaning & Preprocessing

The third task involves preparing a large retail transaction dataset for further analysis.

The workflow includes:

* Importing and examining the raw dataset
* Identifying data-quality problems
* Treating missing values
* Standardizing data types and categorical fields
* Removing duplicate records
* Detecting and controlling numerical outliers
* Converting transaction dates
* Creating additional analytical features
* Performing final validation
* Exporting the cleaned dataset
